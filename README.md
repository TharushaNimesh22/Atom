## Robotics Design & Competition (EN2533) - Atom

## Overview

This project involved the design, development, and implementation of a fully autonomous mobile robot capable of completing a series of complex tasks in a competitive robotics environment. The robot was developed as part of the EN2533 Robotics Design and Competition module at the University of Moratuwa and was required to autonomously navigate, identify objects, manipulate obstacles, and interact with multiple dynamic environments without human intervention.

The robot combined embedded systems, control engineering, sensor fusion, mechanical design, and autonomous navigation algorithms to achieve reliable operation under competition conditions. The system was built around an Arduino Mega–based architecture and integrated multiple sensors and actuators to perform tasks such as line following, wall following, barcode reading, color recognition, object detection, box and ball manipulation, grid navigation, ramp traversal, and arrow-guided navigation.

## Objectives
- Design and develop a fully autonomous mobile robot capable of completing multiple competition tasks.
- Develop reliable object detection and manipulation mechanisms for box and ball handling.
- Implement real-time control algorithms to achieve accurate path tracking and obstacle navigation.

## Technical Features
- Autonomous line and dashed-line following using IR sensor arrays.
- PID-based control algorithms for precise line-following and wall-following behavior.
- Grid-based navigation and position tracking.
- Arrow detection and directional path selection.
- Barcode reading and decoding using optical sensing techniques.
- Color recognition using RGB color sensors.
- Distance-based object detection using infrared distance sensors.
- Box picking and placement mechanism.
- Ball detection and collection system.
- Ramp traversal.
- Wall-following.
- Real-time decision making and task sequencing.

## Hardware Architecture
- Arduino Mega 2560 Microcontroller
- IR Line Sensor Array
- Sharp IR Distance Sensors
- TCS34725 RGB Color Sensor
- NEMA 17 Stepper Motors
- A4988 Stepper Motor Drivers
- Servo-Based Gripping Mechanism
- Custom PCB Interface Board
- Lithium-Ion Battery System
- Acrylic Chassis and Mechanical Structure

The project successfully demonstrated autonomous completion of multiple competition tasks while maintaining reliable navigation, object manipulation, and environmental interaction. The robot provided practical experience in robotics system integration, embedded software development, control engineering, and autonomous decision-making.
